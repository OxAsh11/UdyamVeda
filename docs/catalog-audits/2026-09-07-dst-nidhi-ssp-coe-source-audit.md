# DST/NIDHI SSP and CoE source audit

Date: 2026-09-07

## Records added

- `dst-nidhi-seed-support-program` — NIDHI Seed Support Program (NIDHI-SSP).
- `dst-nidhi-centres-of-excellence` — NIDHI Centres of Excellence (NIDHI-CoE).

These are distinct from the existing NIDHI PRAYAS record. SSP is the intermediary-led seed-support route; CoE is an institutional capacity and startup incubation/acceleration route.

## Captured boundaries

The SSP page states up to INR 100 lakh for a deserving startup through the TBI route and up to INR 1000 lakh for an incubator. The seed record keeps these as separate value buckets and does not present the incubator ceiling as founder funding. The startup route is periodic and call-dependent.

The CoE page describes enhanced financial support over five years for establishing CoEs and startup incubation/acceleration support through periodic calls. It does not state a startup cash ceiling, so this record makes no amount claim and explicitly marks the route as not a guaranteed cash grant.

The NIDHI homepage currently does not display a universal open call. Both records therefore use a call-based window with no asserted current deadline.

## Human review gate

Neither record is publishable yet. A reviewer must verify the current guideline and call, supported TBI/CoE list, applicant category, documents, selection process, milestones, disbursement, reporting, and any grant/equity/debt/convertible, repayment, tax or clawback terms. Review must also confirm the current call status before a deadline or active recommendation is shown.
