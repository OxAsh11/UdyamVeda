## Status meanings

- **Complete:** implemented and verified in the current repository, with no known prerequisite outstanding for that item.
- **Partial:** some code or workflow exists, but live data, integration, coverage, or verification is still missing.
- **Incomplete:** not implemented or only represented by placeholder/static UI.
- **Blocked:** the local implementation is prepared, but an external prerequisite or user-controlled credential/access step prevents verification or execution.
